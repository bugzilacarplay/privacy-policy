# Bugzila Car Play Privacy Policy

This package contains the updated Privacy Policy for Google Play / GitHub Pages.

## Files

- `privacy-policy/index.html`  
  Use this for GitHub Pages at:  
  `https://bugzilacarplay.github.io/privacy-policy/`

- `privacy-policy/index.md`  
  Markdown source for editing in GitHub.

## GitHub Pages deployment

Upload the `privacy-policy` folder to the GitHub Pages repository root.

Expected public URL:

```text
https://bugzilacarplay.github.io/privacy-policy/
```

## Google Play Console

Use the same URL in:

```text
Google Play Console
> App content
> Privacy policy
```

## Notes

This version improves:

- Third-party radio service disclosure
- External support channel disclosure
- Google Play Billing purchase status/token disclosure
- No-sale-of-data statement
