Privacy Policy

App Name: Bugzila Car Play
Package Name: com.bugzilacarplay.app
Effective Date: June 12, 2026
Last Updated: June 27, 2026

Bugzila Car Play ("BCP") respects your privacy. This app is designed for local music playback, online radio streaming, Android Auto integration, Bluetooth metadata sharing, Google Cast playback, Premium features, and Backup & Restore.

BCP does not require user registration or account creation to use the core application.

1. Information We Do Not Collect

BCP does not intentionally collect:

  • Full name
  • Address
  • Phone number
  • Personal contacts
  • SMS or call logs
  • Precise location data
  • Payment card details
  • Personal documents
  • General cloud storage content

2. Local Music Access

BCP may scan local audio files on your device only for media playback. Files remain on your device and are never uploaded to Bugzila servers.

3. Online Radio Streaming

BCP allows playback of third-party online radio streams. When streaming, your device connects directly to radio provider servers. These providers may receive technical connection data such as:

  • IP address
  • Connection time
  • Requested stream URL
  • User agent

BCP does not control third-party radio provider privacy practices.

4. Android Auto

BCP supports Android Auto media playback. During Android Auto usage, media metadata may be shared with the Android Auto system for playback control and display.

  • Station name
  • Song title
  • Artist
  • Album artwork
  • Playback state
  • Queue information

This information is used strictly for media playback functionality.

5. Bluetooth Metadata

BCP may send media metadata to Bluetooth-connected vehicles or audio systems to allow title display and steering wheel playback control.

6. Google Cast

When users start Cast playback, BCP sends media information to the selected Cast device. This may include:

  • Media title
  • Station name
  • Artwork
  • Stream URL
  • Playback state

Cast sessions are started only by user action.

7. Favorites and Settings

BCP stores settings locally on the device, including:

  • Radio favorites
  • Theme settings
  • EQ settings
  • Audio buffer settings
  • Local music scan preferences
  • Cast preferences

8. Backup & Restore

BCP provides Premium Backup & Restore using Android's Storage Access Framework (SAF). Users manually choose where files are saved or loaded.

Your selected file location may be:
  • Internal storage
  • Downloads
  • Google Drive
  • OneDrive
  • USB storage
  • Other Android document providers

BCP does NOT directly access your cloud account. BCP does NOT use Google Drive API, OAuth, or Google Sign-In for backup.

8.1 Included in Backup

  • Online radio favorites
  • Theme settings
  • EQ settings
  • Audio settings
  • Local music scan settings
  • Cast preferences

8.2 Not Included in Backup

  • Premium entitlement
  • Google Play purchase data
  • Purchase tokens
  • Queue and playback position
  • Current playing track
  • MediaSession state
  • Android Auto session
  • Bluetooth session
  • Cast session
  • Developer logs
  • Analytics consent
  • Crash logs
  • Firebase identifiers
  • API keys
  • Local music file paths

8.3 Import Validation

Imported configuration files may be validated for:

  • Schema version
  • File size limits
  • Checksum verification
  • Format validation
  • Rollback on failure

Importing configuration files cannot unlock Premium features. Premium entitlement comes only from Google Play Billing.

9. Premium Billing

BCP may offer Premium as a one-time purchase via Google Play Billing. All payments are processed by Google Play.

  • No recurring subscription unless clearly stated
  • Purchases are tied to Google Play account
  • Restore purchase is supported
  • Backup files do not include Premium ownership

10. Notifications

BCP may send optional mobile notifications such as:

  • App updates
  • Important announcements
  • Feature changes

Android Auto may restrict notification display for driver safety. Some notifications may only appear on the mobile device.

11. Firebase Analytics

BCP uses Firebase Analytics to measure app usage and feature stability. Examples:

  • Radio playback events
  • Favorites usage
  • Cast usage
  • Backup & Restore usage
  • Premium purchase events

BCP does not send sensitive information such as:

  • Config file content
  • Station URLs
  • Purchase tokens
  • Private file paths
  • Personal files

12. Firebase Crashlytics

BCP uses Crashlytics for crash diagnostics and unexpected technical failures. Only sanitized technical error data may be sent.

BCP does not send:

  • File names
  • File URIs
  • Config content
  • Station URLs
  • Purchase tokens
  • Personal data

13. Data Sharing

BCP does not sell user data. Some technical data may be shared only for app functionality with:

  • Radio streaming providers
  • Android Auto
  • Bluetooth systems
  • Google Cast devices
  • Google Play Billing
  • Firebase Analytics
  • Firebase Crashlytics
  • Android document providers during Backup & Restore

14. Data Security

BCP uses reasonable technical measures to protect app data. Exported backup files remain under user control. Users are responsible for where they store backup files.

15. Data Deletion

Users may delete app data anytime by:

  • Android Settings
  • Apps
  • Bugzila Car Play
  • Storage
  • Clear Data

Backup files must be manually deleted by the user.

16. Children's Privacy

BCP is not specifically directed to children under 13. Some radio content may come from third-party providers. Parents should supervise when appropriate.

17. Changes to This Policy

This Privacy Policy may be updated to reflect:

  • New app features
  • Google Play policy changes
  • Billing changes
  • Firebase service changes
  • Security updates
